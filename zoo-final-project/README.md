# 🐾 Zoo Final Project

This is a basic Object-Oriented Programming (OOP) project developed in Java as part of the Amazon Junior Software Developer course.

## 📌 Description

The application simulates a zoo system where different animals can be created and managed. It includes:

- Creation of animals (Tiger, Penguin, Dolphin)
- File management to store animal data
- Interactive console menu
- Basic error handling

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Inheritance and Interfaces
- File I/O (read/write)
- Exception handling
- Console-based interaction
